    bop ¶

    bop(bop_type: BType, s_0: Socket, s_1: SocketLike, fwd: bool = False, rev: bool = False, output_dtype: dtype = None) -> Socket

    Binary operator factory from Sockets.

    Parameters:

    Name Type Description Default
    bop_type BType

    Type of binary operator

    		 required
    s_0 Socket

    First input of the binary operator (must be a Socket).

    		 required
    s_1 SocketLike

    Second input of the binary operator.

    		 required
    fwd bool

    If true, performs operations in place.

    		 False
    rev bool

    If true, exchange s_0 and s_1 (for right-bops).

    		 False
    output_dtype dtype

    output data type

    		 None

    Returns:

    Name Type Description
    out Socket

    Binary operation elementwise result.

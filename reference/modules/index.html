    Writing modules in Python¶

    Stateless ¶

    Stateless()

    Bases: Module

    Class Stateless

    Stateless modules are modules that can be cloned automatically.

    Build an empty module: add tasks with create_task.

    n_frames_per_wave property writable ¶

    n_frames_per_wave: int

    Number of frames processed by each call of the codelets (by default, all the frames).

    create_codelet ¶

    create_codelet(task: Task, codelet: Callable[[Module, Task, SupportsInt | SupportsIndex], int]) -> None

    Set the function executed by a task (its codelet).

    The codelet is called as codelet(module, task, frame_id) and must return 0 on success. Inside it, the data of the sockets are reached with task.<name>.numpy; outputs must be written in place (out[:] = ...).

    Stateful_core ¶

    Bases: Stateful

    Stateful_core is the class that will contain the 'core' of python stateful modules. It inherits from Stateful, and implements the clone method by cloning the python state of the Module's body as well as its own state.

    n_frames_per_wave property writable ¶

    clone ¶

    clone() -> typing.Any

    Return a copy of the module, used to duplicate it on several threads.

    Override it in Python subclasses: create the new instance without calling __init__ (StreamPU copies the tasks, sockets and codelets) and copy the Python state.

    Returns:

    Name Type Description
    out Stateful_core

    the copy

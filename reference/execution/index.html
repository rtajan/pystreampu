    Sequence ¶

    Sequence(*args, **kwargs)

    Bases: _Sequence

    Overlay of streampu._ext.core._Sequence.

    Build a Sequence.

    A sequence can be built from:

    • a socket or a list of sockets: Sequence(out), Sequence([s1, s2]). The first tasks are found by following the bindings backwards from these sockets;
    • its first task: Sequence(task), or a list of first tasks;
    • its first and last tasks: Sequence(first, last).

    The following positional or keyword arguments are those of the C++ constructor: n_threads (default 1), thread_pinning (default False), sequence_pinning_policy and tasks_inplace.

    Parameters:

    Name Type Description Default
    *args Any

    socket(s) or task(s) to build the sequence from, followed by the optional arguments of the C++ constructor

    		 ()
    **kwargs Any

    keyword arguments of the C++ constructor; sockets can be used to give the socket(s) to build the sequence from

    		 {}

    Examples:

    >>> seq = streampu.Sequence(out)        # one thread
>>> seq = streampu.Sequence(out, 4)     # four threads
>>> seq.exec_n_times(100)

    Pipeline¶

    Pipeline ¶

    Pipeline(*args, **kwargs)

    Bases: _Pipeline

    Overlay of streampu._ext.core._Pipeline.

    Build a Pipeline.

    The arguments are those of the C++ constructor, in this order: firsts (first tasks), lasts (last tasks), sep_stages (for each stage, a list [first tasks, last tasks, excluded tasks]), n_threads (number of threads per stage), synchro_buffer_sizes and synchro_active_waiting (one value between each pair of consecutive stages), thread_pinning and puids.

    Parameters:

    Name Type Description Default
    *args Any

    positional arguments of the C++ constructor

    		 ()
    **kwargs Any

    keyword arguments of the C++ constructor

    		 {}

    Examples:

    >>> pipeline = streampu.Pipeline(
...     [source.generate], [sink.send_count],
...     [[[source.generate], [source.generate], []],
...      [[rly.relay], [rly.relay], []],
...      [[sink.send_count], [sink.send_count], []]],
...     [1, 4, 1], [16, 16], [False, False])
>>> pipeline.exec()
